# Resources

This section provides access to the ClimAID manuscript, sample datasets, and supporting materials for users who wish to explore or reproduce analyses.

While ClimAID auto-detects column names and matches them using fuzzy search optimization, sample datasets serve as example for the users. The data inside them are purely representative.  

---

## Manuscript

The ClimAID methodology, modeling framework, and applications are described in the manuscript below.

- [View Manuscript Online](https://doi.org/10.21203/rs.3.rs-9394047/v1)

## Sample Datasets

The following datasets are provided to help users understand the structure and usage of ClimAID inputs.

### Climate Data

[Download Sample Climate Dataset](../datasets/sample_climate.csv)

* This dataset includes:
    - Temperature
    - Rainfall
    - Humidity
    - El Niño Anomalies

---

### Climate Projections Data

[Download Sample Climate Projections Dataset](../datasets/sample_projection.csv)

* This dataset includes time-indexed projections for:
    - Temperature
    - Rainfall
    - Humidity
    - El Niño Anomalies

* It also includes CMIP6 model and the corresponding SSP Scenario.
